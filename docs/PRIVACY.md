# Privacy model

Nikky should collect the minimum context needed for the user-approved workflow.

Core controls:
- category-level learn/no-learn settings
- category-specific retention periods
- correction of learned assumptions
- memory export and deletion
- provider disconnect/revocation
- device/session revocation
- redaction of credentials from action previews
- explicit source/provenance for predictions and actions

Location, files and other sensitive context should not be retained merely because they were observed. Provider scopes should be least privilege, and background monitoring should be transparent and controllable.
